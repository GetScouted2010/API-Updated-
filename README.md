## Getting Started

Below is a list of applications/tools required to configure and run the backend locally:

```
- Node.js (https://nodejs.org/en/download/)
Guides for installation of this are found on the same page (https://nodejs.org/en/download/).

- MongoDB Community Server (https://www.mongodb.com/try/download/community)
This is required to run a local instance of the database rather than connecting to a cloud instance.
* Please note: The installer will ask if you wish to Install MongoD as a service, make sure this box is checked and leave all the default values in.

- (Recommended) (Optional)  MongoDB Compass (https://www.mongodb.com/products/tools/compass)
This is only required if you prefer to utilize a GUI to manage the local database. This guide references MongoDB Compass for ease of configuration.
```

### MongoDB Setup
Upon installation of MongoDB Community Server, Windows will have already started the service and it should be ready to use.

The following steps will assume you are using MongoDB Compass to configure your database.

Open MongoDB Compass, upon launching it will ask for a connection string, you can leave this empty, however if an error occurs, specify the following string:
```
mongodb://localhost:27017
```
You can also enter a name of the local connnection. For this purpose, call it 'TestingDB'

Once this is entered, click Connect.

You will be presented with a window displaying all the databases that were generated by MongoDB. Let's start by adding a new Database by clicking the '+ Create Database' button in the top right of the window. We will call this database 'FB' and the first collection 'players'. From here we can create 4 more collections by clicking on 'FB' in the left-hand pane, and then clicking '+ Create Collection' on the top right, and specifying the name of the collection. These are listed below, and the database hierarchy should look something like this once all the collections have been added:


```
TestingDB
    - FB
        - compatabilityscores
        - players
        - playstyles
        - positions
        - transfers
    - admin
    - config
    - local
    - test
```
The collections labelled 'admin', 'config', 'local', and 'test' are all predefined by MongoDB, however there is no need to add these if they do not exist.

All of the data required can be found in the [MongoDB Dataset Folder.](/dataset)

These can be imported by navigating to the relevant collection in MongoDB Compass, clicking '+ Add Data' > 'Import JSON or CSV File' > Navigate to the folder specified above and select the json file that correlates with the collection that you are adding data to.

Once this is complete, the database is ready to be connected to the API. Leave MongoDB Compass running whilst you need access to the database.

### Express.js Setup

In the root folder of the project (where this readme.md is located), open up a terminal or bash of choice, and run the following command:

```
npm install
```

After roughly 30 seconds, the Node package manager should have fetched and installed all the required dependancies for the project.

From here we can run the API by executing the following command:

```
npm start
```

The server runs nodemon, which will automatically restart when any modifications have been made to the project files. Any calls made to the API should appear in the console with the route used alongside the timestamp of when this was executed.

The API runs on port 3000, as defined in line 6 of index.js, if you wish to change what port this runs on, you can modify the port number on the index.js file.

To stop running the server, use the keybind 'Control + C' whilst the bash window running the API is in focus.

### Optional - Reference if the API fails to connect to the database

Navigate to the [connection URL file](/connections/mainConnect.js) and open this with your text editor of choice. Go back to MongoDB Compass, click the 3 dots alongside the connection 'TestingDB', and click copy connection string, and paste this inside the quotation marks in the url field. We will need to add a pointer to the 'FB' database we are using, so append this value onto the end of the string, as shown below::

```
mongodb://localhost:27017/FB
```

Make sure to save the mainConnect.js file.
